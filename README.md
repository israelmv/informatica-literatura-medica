# informatica-literatura-medica
Este curso de posgrado proporciona las herramientas informáticas, bioinformáticas y metodológicas para la búsqueda sistemática, organización y análisis de la literatura biomédica. Los estudiantes desarrollarán competencias en métodos de búsqueda complejas y la integración de flujos de trabajo digitales reproducibles en ciencias de la salud.
